# judge-domains.authored.txt — the AUTHORED authority for EVERY decision
# surface of the FOHTRACE1 judge (port/foh/judge-foh-trace.js) and of the
# device-side normalizer (port/foh/normalize-foh-trace.js).
# Read by check-judge-regression.sh leg [0n].
#
# WHY THIS FILE EXISTS (Tier A+ round-3b BLOCKER, 2026-07-30).
# ---------------------------------------------------------------------------
# Leg [0g] freezes the judge's decision tables by hashing them. That catches
# CHANGE. It cannot catch LOOSENING, because the frozen bytes are produced by
# running the judge under review through a dumper: the artifact and its
# witness have the same author. The documented remedy for a detected change is
# "re-freeze and say why", so a widening plus a re-freeze is indistinguishable
# from a legitimate edit, and nothing outside the judge disagrees.
#
# This file is that outside disagreement. It is HAND-AUTHORED and each row is
# a CLAIM ABOUT UPSTREAM (or about a registered MENU-SPEC deviation), not a
# dump of anything. Widening a domain, adding an edge, registering a refusal
# token or loosening a line form now requires editing this file too, and the
# edit must state a citation that a reviewer can check and that the widening
# would have to falsify. A re-freeze cannot launder that; it is a second
# signature, in the reviewer's words.
#
# WHY IT COVERS ALL FIVE SURFACES (round-16 / Tier A+ round-4 BLOCKER).
# ---------------------------------------------------------------------------
# v1 of this file authored the `S` value plane only. Both reviewers then
# demonstrated, independently, that the SAME self-derived-pin defect survived
# on every OTHER decision surface: the LAUNCH/TLAUNCH field domains, the
# EDGES set, the REFUSED map, and the normalizer's independent copy of the
# grammar were each witnessed by nothing but their own hash. Stacked
# widenings on those surfaces left both gates green and launched a mutated
# match. Authoring one plane and leaving four is not a fix, it is a smaller
# instance of the same class (HARD RULE 8). All five are authored here.
#
# SCOPE — WHAT THIS FILE DOES AND DOES NOT CLAIM (Tier A+ round-4 MINOR-2).
# ---------------------------------------------------------------------------
# IN scope. For the six row types below, this file is the authority on
#   WHICH values / edges / tokens / line forms are LEGAL, and on the upstream
#   or registered-deviation reason each one is legal. Leg [0n] enforces that
#   the judge and the normalizer agree with it, semantically AND behaviorally.
#   Since round-6 the file ALSO authors the judge's TRACE-INTEGRITY rules
#   (the `X` rows): the SHAPE of a trace -- header, chain continuity, frame
#   monotonicity, launch adjacency and uniqueness, SHOT-name uniqueness, the
#   END line and its transition count. That surface was previously declared
#   OUT of scope on the grounds that legs [5]/[5b]'s negative corpus covered
#   it. Round-6 falsified that: the corpus is a fixed set of hand-made
#   fixtures, so deleting a rule the corpus happens not to exercise is
#   invisible. Every structural rule now has an authored row and a generated
#   corrupt trace that must be rejected by THAT rule's own declared wording.
# OUT of scope, deliberately, each covered elsewhere:
#   - whether the FOH's RUNTIME actually produces a given value on a given
#     screen: that is the flows gate (check-foh-flows.sh) against real
#     device traces. A row here says "legal", never "occurs".
#   - RENDER/layout, timing, audio: no row here constrains a pixel or a frame
#     budget.
#   - the sim/checksum plane: menus are not on the CHECKSUM.md surface at all.
# A row is therefore a NECESSARY condition on the judge, never a sufficient
# description of the FOH.
#
# EDITING RULE: a row moves only together with the upstream/spec change that
# makes it true. If you cannot name the citation, the row does not move.
#
# ---------------------------------------------------------------------------
# FORMAT. One row per line, first token = row type. Comments `#`, blanks
# ignored. Counts are pinned in leg [0n]: 17 S, 16 L, 28 E, 8 R, 2 N, 20 X.
#
#   S <field> <lo> <hi> <screen[,screen...]> <citation...>
#       an `S <frame> <field> <value>` field. lo/hi INCLUSIVE. `screen` list
#       = every screen whose machine may emit the field (the authored
#       SFIELD_SCREENS row).
#   L <line> <field> <lo> <hi> <citation...>
#       a numeric field of the `LAUNCH` / `TLAUNCH` line. lo/hi INCLUSIVE.
#   E <profile> <from> <to> <cause> <citation...>
#       a legal screen transition. profile: `any` | `net` (FOH_NETPLAY 1
#       only) | `nonet` (FOH_NETPLAY 0 only) | `ctl` (FOH_CTL_CHOOSER 1
#       only) | `noctl` (FOH_CTL_CHOOSER 0 only).
#   R <profile> <token> <screen[,screen...]> <citation...>
#       a registered refusal token, bound to the screens that may emit it.
#   N <rule> <value> <citation...>
#       a line-FORM rule the normalizer must share with the judge.
#   X <id> <own|preempt> <citation...>
#       a TRACE-INTEGRITY (structural) rule of the judge: the claim that a
#       FOHTRACE1 trace is constrained in this shape, plus what the emitter
#       does that makes the constraint true. `own` = leg [0n.7] builds a
#       corrupt trace and the judge must reject it with THIS rule's own
#       declared wording. `preempt` = the corruption this rule guards against
#       is caught by an EARLIER rule first, so the rule is defensive depth and
#       cannot fire; the probe proves the PREEMPTION (and names the preempting
#       rule) rather than pretending to exercise dead code.
#
# NOTE ON THE S VALUE ALPHABET: the judge's RE_S_NUM admits only
# (-1|10|[0-9]), so an HI+1 probe above 10 is unrepresentable and leg [0n]
# records it as alphabet-bounded rather than pretending to test it. Leg
# [0n.2] probes the alphabet itself from a FIXED wider token universe
# (-2..12 plus malformed forms), so widening RE_S_NUM is caught by the
# universe, not by the alphabet it widened.

# === N — line-FORM rules the normalizer must share =========================
# The device-side normalizer carries its own independent copy of the grammar.
# Independent copies are the point (a shared module would let one edit move
# both), but nothing outside the two of them said they must AGREE. Round-16
# exploited exactly that: widening the normalizer's NUM to `[0-9]+` while the
# judge kept the canonical form left both gates green. Leg [0n.6] drives the
# SAME authored rows through BOTH programs, so neither can drift alone.
N stokenalphabet -1,10,0-9 judge-foh-trace.js RE_S_NUM admits exactly the tokens `(-1|10|[0-9])` = the UNION of every field's domain: -1 from DEVIATION D5's N/A type cycle (css.js:68, MENU-SPEC §2), 10 from the volume fields' tenths (audiomenu.js:13,101-112, MENU-SPEC §4), 0-9 for the rest. This is the ALPHABET, not a domain: a token OUTSIDE it dies on FORM, a token inside it but outside its own field's domain dies on DOMAIN, and leg [0n] declares which of the two each probe must produce -- so widening the alphabet changes which diagnostic fires and is caught even where the per-field domain rows would still hold.
#   Consequence recorded honestly: HI+1 above 10 is UNREPRESENTABLE in this
#   alphabet, so no probe can test it. That is a property of the grammar,
#   not a gap this file papers over.

# === X — the TRACE-INTEGRITY (structural) plane =============================
#
# WHY THIS SECTION EXISTS (Tier A+ round-6 BLOCKER, 2026-07-30).
# ---------------------------------------------------------------------------
# v2 of this file authored five surfaces, and every row on all five was a
# VALUE/DOMAIN row: which values a field may take, which screen may emit it,
# which edges exist, which refusal tokens are registered, which line forms are
# spelled canonically. Not one row constrained the SHAPE of a trace. So the
# judge's structural rules -- the ones that make a trace a TRACE and not a bag
# of independently-valid lines -- were still witnessed by nothing but leg
# [0g]'s hash of the judge's own source and a fixed corpus of hand-made
# fixtures. Deleting a structural rule that the corpus does not happen to
# exercise is exactly the self-derived-pin defect this file exists to close,
# one surface further out.
#
# WHAT AN X ROW CLAIMS. Not "the judge has this line". Two things the judge
# cannot say about itself: (1) a FOHTRACE1 trace is constrained in this shape,
# and (2) the EMITTER makes that constraint true -- the citation names the code
# that produces the shape. A widening that drops the rule falsifies claim (1)
# by hand, and the row cannot move without an emitter change to cite.
#
# THE EMITTERS. Two: the host driver (foh_app.c -- header :437, T :491,
# S :518-520, TLAUNCH :528, LAUNCH :532, SHOT :565, END :571, fclose checked
# :575) and the device driver (foh_dev.c -- lines buffered in RAM by tr_line
